# PiDeck 内置能力

这是 PiDeck（Go + NSGo 原生桌面端）的能力索引，不是 PiDeck Electron 版的手册。
不确定某个入口时先让用户打开对应设置页，不要凭 PiDeck 旧版的文件路径或 HTTP 接口猜。

## 生图

- 用户在输入框切到「生图模式」，或从命令面板执行「生成图片…」。
- 供应商与模型在「设置 → 模型与认证 → 生图」配置；客户端不直接保存一份独立的生图配置。
- 生成结果显示在输入框里，可以直接发给当前会话，或在生图对话框里另存。
- 不要按旧版 PiDeck 的 `imagegen.json` 读取配置，也不要在对话里回显 API Key。

## 诊断

- 让用户打开「设置 → 诊断」：可复制诊断报告、导出诊断包、打开日志目录。
- 诊断包已脱敏配置与插件摘要；会话正文和凭据不在里面。
- 崩溃记录在数据目录的 `crashes/`，下次启动会提示一次。

## 手机与远程

- 「设置 → 远程」可以复制连接链接或出示二维码。
- 手机端只通过远程 HTTP 接口工作，不加载桌面扩展或本地文件能力。
- 需要自建中继时，按发布包里的 `pideck-relay` 说明部署；不要让 agent 直接改远程配置。

## MCP

- MCP 服务器在「设置 → MCP」里管理，配置由 pi 保存在 `mcp.json`。
- 需要接新服务时使用 `mcp-setup` 技能，按服务官方文档写配置并用 `pi mcp list` 验证。

## 技能与提示词

- 技能：设置 → 资源，可打开技能目录；「技能商店…」从索引或 skills.sh 安装。
- 提示词：提示词库的「提示词商店…」；「扩展商店…」管 pi 扩展。
- 内置扩展随应用携带，可在资源页点「更新内置扩展」按 PiDeck 的清单校验后更新。

## 边界

- 会话文件归 pi 所有；不要手改别的进程正在写的会话。
- 不要为了一个界面操作去改 `config.json`；优先让用户走设置页。
- 遇到 pi 原始报错，原样转述，不要改写成 PiDeck 的报错。
