PiDeck v0.9.0 正式版已发布！本次带来独立宿主插件系统、每轮回复的模型标注、内置外网访问，以及一批会话与终端体验改进：

**v0.9.0 · 重点更新**
- **独立宿主插件系统（主打）**：不依赖 pi 进程的本地 HTML / CSS / JS 插件，可注册弹框或工作区页面式面板、侧栏入口与命令面板动作，按授权读取当前项目会话、定位消息并保存私有状态，主题与语言跟随应用。支持从文件夹或 `.pideck-plugin` 文件安装，设置页可生成脚手架；授权绑定逐文件内容指纹，插件内容变化必须重新确认。
- **每轮回复标注实际使用的模型**：会话里经常换模型，事后却看不出某轮回复是哪个模型给的。现在每轮回复底部（耗时读数之后）显示该轮实际使用的模型名小标签，悬停可看「供应商 / 模型」全名；历史、实时与 DSH 会话都覆盖，数据直接取自会话记录，不额外落库。
- **模型目录自动后台更新**：此前只有手动点「更新目录」才会拉取模型目录，pi 发新版本后目录会一直停在旧版；现在启动后检测到远端有新版本就在后台自动更新，不阻塞界面，不想自动跑可在设置里关闭。
- **内置外网访问与访问令牌**：Web 服务新增 cloudflared 免注册临时隧道与 Tailscale Serve 两种入口，配套操作指南与参数设置；远程访问受可撤销的访问令牌保护，不再仅依赖「地址不易被猜到」。
- **Web 实时推送与计划模式**：会话状态和桌面端发起的回复改为 SSE 实时推送，不再高频轮询；手机端输入框也支持计划模式。
- **右侧边栏上下分区 + 会话状态面板**：右栏下半区常驻展示当前会话的待办 / 修改文件 / 子代理，高度可拖拽、比例跨重启保持；新增「会话状态位置」设置，可在「输入框上方横栏」与「右侧边栏下半区」之间二选一。
- **TPS 测量模式**：「每秒 token 数」现在可选流式（输出 token ÷ 首字到完成）或端到端（含等待首 token），标签标明当前口径；切换后输入框统计、会话状态与上下文计量即时跟随。
- **终端设置、WebGL 与快照回放**：新增终端设置页（主题共用统一数据源），支持 WebGL 渲染与终端快照回放，关闭终端前提供确认。
- **生视频独立后端**：与生图平行的独立后端，直连供应商视频 API；任务受理即持久化占位，取消 / 网络抖动 / 重启都能恢复，产物以流式 `<video>` 卡片呈现，可播放、取消与另存。

**其它值得一看**
- **繁体中文界面**：新增 zh-TW，覆盖主工作台与浮窗。
- **Logo 可换自定义图片，并可设置应用显示名称**：源图自动缩到 512×512 内、统一输出透明 PNG，品牌区 / 窗口 / 托盘 / 任务栏 / 开屏全部跟随，无需重启。
- **把 PiDeck 自身通过 MCP 暴露出去（默认只读、默认关闭）**：任意 MCP 客户端可列出已授权项目与其已保存会话、分页读取条目、按标题搜索；写开关单独解锁「停止响应」。
- 还有：项目置顶与拖动排序、右侧「分支」面板浏览 pi `/tree`、通知历史跨重启可查与「仅失焦时提醒」、输入框功能按需显示、用户消息图片可复制 / 保存 / 移除。

**重要修复**
- **提示词增强不再卡在启动超时**：托管安装的 SDK 体积大，冷缓存叠加杀毒扫描可能超过 15 秒；启动等待放宽到 30 秒，超时判定不再误杀已经握手的助手，并补齐启动阶段日志与子进程 stderr 摘要。 (#341)
- **缺少原生模块不再让整个应用起不来**：node-pty 改为惰性加载，跨架构打包或基线较旧的 Linux 发行版不再一启动就崩。 (#257)
- **新会话首条消息不再丢掉刚选的模型** (#340)、**代理白名单接管时主开关给出解释** (#342)、**选择题点击即提交** (#344)。
- **上下文圆环的「系统 + 工具」不再常显示 0**：改为从会话记录直接测量，三段图例与 DSH 会话一致，每个数字的悬停提示写明来源。
- **停止响应更精准**：不再误伤下一轮回复，正常结束或关闭后不再弹迟到的「停止较慢」警告；出错会话的「关闭 Agent」也能可靠收敛。
- **终端更稳**：并发关闭标签不再复活、切换归属不串输出、提前退出状态不丢、启动命令不再因提示符早到而漏发。
- **应用、配置与数据目录统一为 PiDeck 命名**：存量安装首次启动由幂等迁移器接管（改名数据根、修正会话 header、原子改写配置），失败不阻塞启动、下次启动继续补修。
- 另有：重发 / 编辑后保留已选模型与图片、二级 fork 历史读取不再重复或混入父分支消息、扩展版本检查在网络失败时保留本地已装版本、Windows 任务栏按钮显示 PiDeck 品牌而不是 Electron 标、20 个主题色恢复对比度、弹窗 Escape 关闭与键盘可达性修复等。
