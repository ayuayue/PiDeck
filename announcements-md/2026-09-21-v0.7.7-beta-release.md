**v0.7.7-beta 预发布版**已经打出来了，先发出来给大家提前试用；正式版会在验证之后跟进。

**新功能**

- **工作区文件按名称搜索（#215）**：文件面板新增搜索入口，输入即搜、穿透任意深度，超大 monorepo 也能秒级拿到够用的结果；
- **从其他目录导入会话**：项目移动 / 改名后不必手工搬 JSONL，直接找回历史；
- **外部资源导入（MCP / 技能 / 提示词）**：支持从外部来源导入，读写边界先校验再落盘（感谢 @zx3022448，PR #221）；
- **严格工具采样开关进界面**：上一条公告里让大家手改 `supportsStrictMode` 的操作现在有开关了——供应商表单 →「严格工具采样」三态（跟随 pi 默认 / 开启 / 关闭），不用再改源文件、也不用重启客户端；
- **模型目录更新到 pi 0.86.1（1443 个模型）**：新增 radius、meta 两个供应商，amazon-bedrock 补齐区域前缀，openrouter 刷新到 380 条；设置 → 模型目录点「检查更新」即可拉取，不必等发版；
- **供应商 / 模型 / 认证支持隐藏与自定义排序**，新增「切换模型」`Ctrl+M`、「思考强度循环」`Ctrl+T` 快捷键；
- **DSH host 可手动停止（跨重启持久）**，DSH 配置目录与 dsh CLI 共用的覆盖风险现在会在界面上分级提示（#189）；
- **Windows 资源管理器右键直接发起「小任务」**：选中目录即开一个只管输入的紧凑窗口，关掉窗口任务继续跑（感谢 @r0y1z2，PR #243）。

**修复**

- **第三方中转站拉不到模型 / 手填模型也用不了**：代理注入补上 `NODE_USE_ENV_PROXY=1`（undici 默认不读代理环境变量），关闭桌面代理时也不再强制直连；
- **pi 0.86 的 system 条目不再让编辑 / 删除落到相邻条目**；DSH 新版（v1+）会话重新可见，「加载更多对话」改按轮分页、失败不再静默；
- **提问卡钉在列底接管输入栏、选项改整行横条**，长文案不再被栅格压成窄条（#230）；
- **文件链接支持 `Ctrl/⌘ + 左键`用默认应用打开**，无后缀文件与目录路径也可点击（#229）；
- 其余修复见更新日志：会话 Tab 宽度上限收紧、窗口不再恢复到屏幕外、通知详情弹窗统一 markdown 渲染等。

**获取方式**：预发布版不一定出现在所有更新通道上——可以在「设置 → 更新」点「检查更新」，或到 [GitHub Release 页面](https://github.com/ayuayue/PiDeck/releases) 手动下载安装包。不想尝鲜的话，等 v0.7.7 正式版即可。
