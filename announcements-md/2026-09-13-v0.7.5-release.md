PiDeck v0.7.5 正式版已发布！本次版本亮点：

**新功能**
- **定时任务与自动化**：可视化 Cron 编辑、工作/计划/目标模式、运行历史，DSH 会话也支持定时运行；
- **AtomGit 优先更新源**：国内用户更新检查更稳（GitHub 官方兜底），更新弹窗内可直接查看版本更新日志；
- **内置扩展热更新**：无需等待发版即可在线更新内置扩展（新增「删除前移入回收站」扩展）；
- **引用芯片升级**：内联/气泡引用统一新样式，切换会话或重启后引用不丢失，文件树支持目录引用；
- **侧栏会话悬停预览卡片**：悬停 1.5 秒即可预览会话内容，无需先打开；
- **可配置 Git 路径**：支持自动检测 / 手动指定 Git 可执行文件；
- **DSH 运行时升级至 0.1.5（Typert Remote）**：全新中立远程通道，接口面更完整；
- **Linux arm64 支持**：新增 deb / AppImage / tar.gz 构建产物。

**修复**：AtomGit 镜像源更新检查 404、DSH 沙箱挂起与黑窗口、第二及后续 DSH 会话无响应、内置 Todo 扩展计划缓存冻结等多项问题。

**查看更新日志**：
- 点击左上角 **PiDeck 图标** → 「更新日志」，应用内直接查看；
- 或查看 [GitHub Release 页面](https://github.com/ayuayue/PiDeck/releases/tag/v0.7.5)（含完整 CHANGELOG）。

建议在「设置 → 更新」中确认已选择常用更新源，保持最新版本。
