PiDeck v0.7.9 正式版已发布！你当前使用的版本尚未升级，本次带来了近两个版本的重点更新，建议尽快升级体验：

**v0.7.9 · 悬浮球与极简浮窗（主打）**
- **悬浮球**：开启后关闭主窗口不再退出，而是收进一颗半透明毛玻璃小球；任务在后台继续运行，随时点开继续；
- **极简浮窗**：点击悬浮球展开 480×640 小窗——当前会话的完整对话与输入，可切模型、可切任务模式；浮窗主页支持新建会话（选项目、选模型）、继续最近会话，并新增**活动会话直达**：正在运行 agent 的会话排最前带脉冲绿点，点击直接进入，跨项目无需先选项目；
- **新会话秒级激活**：standby 运行时池提前预热 pi 进程，新建会话不再等待启动；
- **托盘右键菜单丰富化**：悬浮球显示/隐藏/退出等常用操作直达；
- **插件开发接口**：能力目录 + AI 开发指南 + demo，AI 可以直接帮你写 PiDeck 插件；
- **导入 Kimi 会话**：支持 Kimi Code / Kimi Work / MinimaxCode；
- **适配 pi 1.0.x**：资源管理改走 pi 原生配置；
- **体验与修复**：设置页会话压缩改百分比滑条、新会话保留上次使用的模型、启动不再闪现引导页、Win11 贴边窗口精确恢复、悬浮窗贴边与置顶语义优化、会话时间戳不再无故刷新等。

**v0.7.8 · 数据目录更名与自定义主题**
- **数据目录更名为 PiDeck 并自动迁移历史数据**：升级后首次启动自动完成迁移，会话/设置/扩展配置不丢失；
- **自定义主题**：JSON 主题包 + AI 开发指南，配色随心换；
- **用量查询新增「火山方舟 AK/SK」模板**。

**如何升级**：
- 应用内点击「设置 → 更新」检查更新，或前往 [GitHub Releases](https://github.com/ayuayue/PiDeck/releases/tag/v0.7.9) / [AtomGit Releases](https://atomgit.com/ayuayue/PiDeck/releases/tag/v0.7.9) 下载安装包。

**查看更新日志**：
- 点击左上角 **PiDeck 图标** → 「更新日志」，应用内直接查看完整 CHANGELOG。
