PiDeck v0.7.6 正式版已发布！本次为大型更新，重点包括：

**新功能**
- **快捷键自定义与 Ctrl/Cmd+P 命令面板**：打开设置 / 新建会话 / 搜索 / 开发者工具均可改键；命令面板可模糊跳转全部设置项与配置页，也能直接执行「重启 / 停止 Agent、新建会话」等操作；
- **提示词官方模板与内置技能热更新**：与内置扩展同款覆盖层机制，远端校验、原子替换，写入即见无需重启；
- **导入 Cursor Agent 会话**：项目右键扫描 `~/.cursor/projects`，一键转成 pi 原生会话；
- **定时任务支持项目级作用域**，管理界面改为模态弹框，不再打断当前会话；
- **会话 Tab ⋯ 菜单新增当前会话操作**（重命名 / 复制 / 导出 HTML / 打开会话文件等），文件路径链接支持右键菜单，侧栏与 Tab 菜单可复制 Agent ID；
- **提问卡支持直接回车提交**（IME 合成安全），批量卡新增进度条；
- **上下文接管扩展的压缩改写**：装有 Magic Context 等接管压缩的扩展时，压缩按钮自动改写为其自有命令，不再「点了没反应」；
- **安装包瘦身**：官方安装包默认不再随 DSH runtime，首次使用按需下载，同时裁剪无用 DLL 与字体资源。

**修复**
- **稳定性**：生图会话 OOM 白屏、超大会话（数亿字符）打不开或闪退、常驻缓存无界增长、主进程堆占用过高等内存与崩溃问题全面治理；
- **pi 启动链路**：启动失败毫秒级报错不再静默等待，Windows 统一走 node 直启，扩展禁用原因透明化，内置扩展热更新自带运行时依赖（修复 2026-09-15 扩展全禁事故）；
- **兼容性**：DeepSeek 中转站两个 400（developer 角色与 reasoning_content 回传）、模型偏好失效阻断发送、导入会话格式不规范等问题修复；
- **体验**：时间线吸底与上滑翻页不再被布局增高拽走、自动命名标题恢复（推理模型）、自定义提示音可播、公告与更新源弃用 jsDelivr、Linux 升级后双击图标没反应等十余项修复。
