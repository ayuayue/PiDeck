# 字体与排版

这份文档是界面字号、行高、字重与颜色的一份参考：默认值是什么、为什么、
以及每类文本落在哪一档。来源是原 Electron 版 PiDeck 的排版系统
（`foundation.css` / `timeline.css`），按本项目（Go + NSGo）的能力做了取舍。

## 一、参考：PiDeck 的默认排版

PiDeck 用 CSS 变量把字号拆成七档 UI token、四条轨道（UI / 标签栏 / 聊天正文 /
输入框），过程层（思考、工具调用）再从正文派生。

| Token | 浅色默认 | 行高 | 用途 |
| --- | --- | --- | --- |
| micro | 11px | 16px | 最小的徽标、计数 |
| tab | 11px | 16px | 会话/文件标签栏 |
| caption | 12px | 18px | 说明、次要信息 |
| control | 13px | 20px | 按钮、菜单行、控件标签 |
| body | 14px | 22px | 面板正文 |
| chat | 16px | 1.6（25.6px） | 会话正文（回答、提问） |
| input | 14px | 22px | 输入框 |
| title | 16px | 24px | 标题 |
| brand / heading | 18 / 20px | — | 品牌字标、页面标题 |
| logo | 36px | — | 起始页大标题 |

过程层（`timeline.css`）：

- `chat-row = max(13px, chat − 2)`，行高 1.54：思考标题、工具行、过程组头；
- `chat-detail = max(12px, chat − 4)`，行高 1.5：折叠预览、耗时、路径、徽标、diff 计数；
- **降权只靠颜色 / 字重 / 填充，不靠缩小字号**（字号是用户的可读性设置，
  用户调大正文时过程行也要一起变大）；
- 组头与成员行同一档字号，组头用 500 字重 + tertiary 颜色，成员行 400；
- 思考正文比回答小一档，字重 350，颜色 tertiary，身份色（`#6366f1` / 暗色
  `#818cf8`）只给 Brain 图标。

颜色（浅色 / 暗色）：正文 `#202124` / `#ecece7`，次要 `#4a4a4a` / `#b8b8b2`，
过程文本 `#666666` / `#9a9a94`，元信息 `#9a9a9a` / `#a0a09a`；工具身份色
`#1d4ed8` / `#60a5fa`。

字距：CJK 正文**不设负字距**；只有小号等宽标签（分组标题、角标）加
`+0.4 ~ +0.6px` 的轻微拉开。数字（时间、耗时、计数）一律等宽数字（tabular），
避免每秒跳动带动布局。

## 二、本项目的映射

默认会话字号与 Electron 对齐到 16 pt，行高 1.6，默认阅读列 80%。过程层保留下限，
移除上限，用户选择大字号时，思考与工具详情也会放大。SDK 的折叠摘要仍为固定 13.5，
不再以它限制实际内容的可读性。已保存的自定义字号、宽度与字体继续生效。

界面使用 Electron 的系统无衬线字体栈，Windows 默认优先微软雅黑 UI，其他宿主使用系统 UI、
苹方、HarmonyOS Sans 或 Noto Sans CJK。当前 NSGo Windows 适配器只选字体列表中的首个
可用字体，所以这里不能照搬以 Segoe UI 开头的 CSS 列表。等宽栈保留 CJK 回退声明，
但 Windows 代码中缺失的 CJK 字形仍由 DirectWrite 决定，不宣称完全控制该回退。
应用根视图显式应用有效字体，主题字体与用户字体覆盖使用同一份解析结果。

### 颜色三级

正文 → 过程 → 元信息，用三档墨水承担层级，不靠字号差：

- `Text`：回答、提问、正文里的强调；
- `Text` 基线为浅色 `#202124`、暗色 `#ecece7`；
- `Muted`（浅色 `#666`，暗色 `#9a9a94`）：思考、工具行、说明文字；
- `Faint`（浅色 `#9a9a9a`，暗色 `#a0a09a`）：时间、耗时、路径、预览、计数。

身份色只用于图标，不用于正文：思考的 Brain 用 `thinking`
（浅色 `#6366f1`，暗色 `#818cf8`）；工具执行中用 `Info`
（浅色 `#1d4ed8`，暗色 `#7aa2ff`），结束后回到 `Muted`。

### 规则

1. **过程层派生**：`row = max(13, 正文−2)`，`detail = max(12, 正文−4)`；
   改聊天字号，思考与工具行一起变；最小档位用下限保护可读性。
2. **降权靠颜色与字重，不靠再缩小字号**；折叠条（套件）与过程行同属 500 字重档。
3. **正文与中文不设负字距**；仅小号等宽标签加 +0.4~+0.6 字距。
4. **数字等宽**：时间、耗时、diff 计数、工具毫秒数都用 tabular，避免跳动。
5. **等宽只给标识符**：路径、模型名、代码、参数、计数；句子和正文用界面字体。
6. **不叠加多重强调**：同一行最多一个 500 字重 + 一档颜色，不额外加底色盒子
   （工具行默认平铺，悬停 4% 墨水，展开 3% + 顶部发丝线）。
7. **Markdown 比例对齐原版**：h1–h6 为正文的 1.3 / 1.15 / 1.06 / 1.03 / 1 / 0.95 倍，
   标题行高 1.3；行内代码 0.875 倍、代码块 0.92 倍，段落间距 0.7 倍。其余 SDK 文本
   以 `ui.TypeBody.FontSize` 为基线缩放，避免修改默认字号后细节反而缩小。

### 定时任务表单

任务名称、cron 表达式、超时和提示词保留可见标签，标签与占位文字使用 `Muted`，
输入内容使用 `Text`；「保存后立即启用」同时显示开关与文字说明。
弹窗宽度跟随内容宽度设置，最大 760 pt；小窗口中正文独立滚动，保存、取消与完整校验提示
留在底部。项目名过长时单行省略，避免撑出横向滚动。

### 定时任务运行历史

每条记录先列任务名、状态、时间和操作，任务名在窄窗中弹性收缩。错误正文另起一行，
使用 11.5 pt / 17 pt 行高与 `Muted`，保留换行并自动折行，可选择文字；有错误时提供
「复制」按钮，鼠标点击或键盘回车都复制完整原文。即使未能创建会话，也能直接阅读和复制
失败原因。历史区域独立滚动，滚动条留出空间，长错误不撑宽面板。

### 会话搜索

结果汇总按当前「全部 / 标题 / 正文」范围计算完整会话数和正文匹配数；首批渲染 60 条，
通过「加载更多」每次追加 60 条，直到全部可浏览。追加时保留阅读位置；切换范围或搜索词时
回到首批。列表独立滚动，为滚动条预留空间；最小桌面窗口中搜索框、重建索引与关闭按钮
始终可见。

### 侧栏与抽屉（本轮对齐）

左右两栏是「导航面」而不是正文：行高与字号按 Electron 版的行模型取整，不再逐处写小数。

| 位置 | 字号 | 行高 | 其它 |
| --- | --- | --- | --- |
| 侧栏会话行 / 项目行 / pi 历史行 | 13.5 | 19 | 行高 32，左右内边距 8，行距 2 |
| 侧栏「新建会话 / 搜索会话 / 更多」 | 13.5 | 19 | 行高 32，图标 15（主行动作 500 字重） |
| 侧栏分组标题（置顶 / 今天 / 本周） | 11 | — | 500 字重，Faint，上留 10 |
| 侧栏列标题与计数（项目 N） | 11 | — | 计数等宽数字 |
| 侧栏底栏与顶栏图标 | — | — | 按钮 30，图标 15.5 |
| 侧栏会话行时间 | 10.5 | — | 等宽数字，Faint |
| 会话标签 | 13 | 18 | 高 30，状态点 6 |
| 抽屉页签 | 套件 SizeDefault（13） | — | 下划线变体 |
| 抽屉节标题（上下文 / 待办 / 用量 / 这个会话） | 11 | — | 600 字重 + 0.4 字距，Faint |
| 抽屉列表行（待办、改动、关联、用量标签） | 11.5–12.5 | 17–19 | 行高 22–26，行距 2–3 |
| 抽屉路径行（工作目录 / 会话文件） | 11 | — | 等宽，行高 24，行内带复制与「⋯」 |
| 抽屉用量数字 | 13.5 | — | 600 字重等宽数字，输入/输出/费用分两行两列 |

节与节之间是 16 点内边距 + 一条 `line` 发丝线；抽屉自身的底色是 `surface`（白/深灰面板），
让它与正文画布的区别由底色和一个像素的分界线共同承担，而不是两边都是灰。

### 分隔线的三个角色

`internal/viewkit/theme.go` 里只有两个线角色，职责分开：

- `Border`（浅色 `rgba(13,13,13,0.13)`）：控件边框，如按钮、输入框、菜单卡；
- `Line`（浅色 `rgba(13,13,13,0.07)`，暗色 `rgba(255,255,255,0.07)`）：块内分隔，
  如抽屉里两节之间的发丝线、侧栏内 `更多` 与三栏之间的线。

区域边界（左右侧栏与正文之间）不另外画线：它由 `ui.SidebarShell` 的拖动把手画，
而把手取的是 `Border`，所以边界比块内分隔明显一档、又是同一条一像素的实线，
既不会糊成阴影，也不会比卡片边框更重。改 `Border` 会同时影响控件与这两个边界，
所以它的值按「边界读数」定，而不是按「控件读数」。

### 没有采纳的部分

- PiDeck 的「全局 UI 字号」：NSGo 的全局文字缩放由宿主
  `Env.FontScale` 控制，应用侧不能设置；我们的字号是逐视图常量，
  要做全局 UI 缩放需要先把 500+ 处字号抽成 token，暂不做。
- 输入框仍保留「0 = 跟随聊天」的配置语义，不把用户已有的跟随设置改成原版固定 14。
- SDK 摘要折叠条与通用按钮仍使用套件尺寸；本轮不复制套件的状态机。

## 三、设置里的入口

设置 → 外观：

- **聊天字号**：14 / 16 / 18 / 20 pt（默认 16），正文、提问、思考、标题、代码同比例；
- **聊天行高**：1.45 / 1.6 / 1.8 / 2.0 倍（默认 1.6）；
- **输入框字号**：跟随聊天 / 14 / 16 / 18；
- **界面字体**：任意已安装字体，留空跟随主题；回车、失焦或「应用」生效；
- **等宽字体**：代码、工具输出、编辑器、终端、路径与标识符；
- 编辑器字号（11–20）、终端字号（8–20）归入「界面与工具」；内容宽度（50%–100%）保留在「通用」。

### 设置导航与说明

- 导航按「偏好设置 → 模型与运行 → 扩展与连接 → 数据与维护」组织；先放日常偏好，再放模型、工具接入及维护入口。分组和显示名称不改变原有页面 ID。
- 页面摘要解释 pi、MCP、Token 等术语；旧的「模型与认证」「资源」名称仍可通过设置搜索找到。
- 分组标题使用 11 pt 的半粗常规界面字体和 `Muted`；设置说明完整换行，不以两行省略隐藏使用条件。
- 设置行按可用宽度换行；空间不足时控件移到说明下方，避免挤窄说明或横向溢出。
- 外观页依次呈现配色、阅读与输入、界面与工具、字体、主题文件及品牌与背景设置。
- 「默认思考等级」只影响之后创建的 pi 会话；「使用 pi 默认值」清除应用层覆盖。选择后立即更新选中态，配置保存放到后台。

### 工具与扩展设置的交互

- 快捷键的用户设置优先于插件贡献；留空并回车会解绑，原插件快捷键不再触发该命令。已解绑的命令仍显示在列表，可用「默认」恢复。
- 添加 MCP 服务器时显示等待状态；操作结束前禁用取消、Escape 和点按背景关闭，且不会重置成另一份表单。成功提示使用实际提交的服务器名称。
- 技能与扩展页按配置显示包的真实启停状态；停用的包显示「已停用」，不再误称「自动加载」。包是否可在此切换与其启停状态分开处理。
- 插件页的操作按钮可换行，长译文和窄设置栏中仍能完整操作。

### pi 设置的范围与输入

- 页首先说明设置写入本机 pi 的 `settings.json`，供之后启动的 pi 进程使用；不会立即更新当前会话，也不影响 ACP。
- 「默认思考等级」与「通用」页的覆盖关系明确区分；压缩设置解释 Token 的含义，并为预留量、近期历史保留量各设独立标签。
- 数字框打开时带入已保存的值，回车或失焦提交。非整数、负数及超出整数范围的输入只在本地显示错误，不改配置；留空或 0 清除本项数字覆盖。
- 缺失的重试和压缩开关按 pi 的默认开启状态显示。后台保存按操作顺序执行，只合并本次改变的字段，保留缺省状态、未知配置和其它已存在的设置。

### 运行环境的代理与目标状态

- 代理说明区分应用内 HTTP 直连与 Git、Agent 对启动环境的继承；明确回车或失焦保存，以及 Agent 进程需要重启的生效边界。
- 代理输入框的可访问名称随界面语言翻译；后台环境探测只更新结果区，不重建正在编辑的命令与代理输入框。
- WSL 与 SSH 状态以名称和完整详情分行展示，正常详情使用 `Muted`；路径、长名称与错误原因按列宽换行，不截去排障所需的末尾信息。
- 添加工作区的按钮按可用宽度换行，在 420 pt 设置内容栏和长译文下仍可见且可由键盘聚焦。

### 高频导航的动效

- 顶部会话、左栏栏目与底部终端使用持续存在的选中标记，以 180 ms EaseOut 跟随选择；快速连续切换从当前显示位置继续转向最新目标，首次显示和普通重排不做入场动画。
- 标签和输入节点保留身份，原有菜单与键盘操作保持可用；终端标签始终预留相同边框，不因选中改变宽度，也不为一次选择触发整窗布局动画。
- 应用的「减少动效」与系统减少动态效果均立即到达选中状态；中途开启时只停止并重置装饰层，不重建标签或输入框。
- 顶部标签的延后定位只处理最新选择，丢弃过时请求；减少动效时直接定位，不播放滚动过渡。

### 历史消息的阅读位置

- 切回会话时，用该会话保存的滚动偏移初始化消息列表，保留阅读位置、跟随选择和输入草稿。
- 后台历史就绪回调只在原本跟随最新消息时滚到末尾；用户向上阅读后，仍可用键盘主动「跳到最新消息」并恢复跟随。
- 程序滚动完成前的平台旧坐标回报不覆盖保存的位置，也不改变是否跟随最新消息。
