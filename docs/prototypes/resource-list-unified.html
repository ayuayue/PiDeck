资源页统一改造原型 · 扩展 / 技能 / 提示词

目标：三个资源页共用一套「范围 + 筛选 + 搜索 + 行级标签 + 启停开关」交互；去掉分组框与「继承」概念；修复重复列出。

统一边界（本原型演示部分）：① 作用域选择器 = 全局 + 全部已注册项目（可直接切换）；② 筛选分段 = 全部 / 已启用 / 未启用；③ 搜索框（按名称/来源过滤）；④ 行级来源标签 = 内置 全局 项目；⑤ 行级启停开关（启用 = 主题色高亮）；⑥ 全局视图不分组，只保留「内置」徽标；项目视图分组：项目组在上、全局组在下，组内行带来源标签。托管行（包/设置声明）与普通行按来源去重，同源只出现一次。

✅ 统一为公共组件（三个页面共用）

  • 作用域选择器：全局 + 全部已注册项目（可直接切换，不再只有当前项目）
  • 筛选分段：全部 / 已启用 / 未启用 + 搜索框
  • 行级来源标签：内置 / 全局 / 项目
  • 行级启停开关：ToggleLeft / ToggleRight，启用 = 主题色高亮
  • 表格容器：表头 / 空态 / 加载态 / 计数

🔵 保留各自差异（不强求统一）

  • 列结构：扩展 = 扩展/版本/路径/操作；技能 = 名称/描述/路径/操作；提示词 = 名称/描述/操作
  • 行操作集：扩展 = 开关+更新+复制指令+卸载+打开位置；技能/提示词 = 开关+编辑+重命名+删除
  • 创建表单：扩展无；技能/提示词有（名称/描述，技能另有位置选择）
  • 商店子页：pi.dev 目录 / 技能商店 / 提示词商店 内容完全不同
  • 扩展专属：白名单总开关、全部更新、内置扩展恢复

🔴 移除 / 修复

  • 全局视图不再套分组框，只有「内置」徽标（全部都是全局来源，无需分组）
  • 项目视图保留分组：项目组在上、全局组在下；组内行仍带来源标签（内置/全局/项目）
  • 移除「继承」概念与相关文案（改行级来源标签）
  • 修复重复列出：托管行（包/设置声明）与普通行按来源去重，同源只出现一次
  • 全局范围 = 只显示全局内容（含内置）；项目范围 = 项目 + 全局 混合
