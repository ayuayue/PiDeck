# 会话导入

可以从项目中的「导入会话」入口读取该项目的历史，也可以从全局入口查看其他项目的记录。导入后生成应用自有的 pi 会话副本，源工具的历史文件保持原样。

## 工具过程与时间

Claude Code、Qoder 和 Codex CLI 的历史会保留工具调用及其结果之间的对应关系。同一批工具的结果可以分成多条记录返回，返回顺序也可以不同于调用顺序；导入后仍显示在对应工具下，并保留结果的错误状态。

Codex 把调用与结果放在同一条记录中的联网搜索、生图和子代理回报，也按工具过程导入。源记录未保存的搜索正文或图片仍采用现有提示，不补造内容。

连续的 AI 内容片段合并成一条回复，时间取该回复第一个片段的时间；思考片段也计入。后续回复使用各自的时间。

## 修正已有导入副本

导入列表显示「有更新」时，可以选择对应会话重新导入。更新会替换应用内先前导入的副本；如果在副本里继续过对话，先导出需要保留的内容。

本次修正将 Claude Code、Qoder 和 Codex CLI 的转换器版本更新为 2。旧版本生成的副本即使源文件未变，也会显示「有更新」，由用户选择是否重新导入。源文件不会被修改。
