# 桌面端右侧栏

右侧栏按“概览、文件、Git”组织，沿用应用当前主题。切换入口和现有文件、仓库操作保持一致。

## 侧栏与设置的文字层级

- 以右侧 Tab 的 13 点文字为基准，左侧分栏、项目名、会话名及设置导航共用 `PanelTextSize`；单行列表采用 20 点行高，保留多行历史条目的独立排版。
- 项目分组、设置分组和说明采用 12 点辅助层级；计数、快捷键与状态等元数据保留更小字号，设置页标题为 16 点。
- 设置导航选中前后保持常规字重，以现有主题底色区分状态；导航、搜索结果和主要设置输入框采用 32 点高度。通用设置与外观字体输入复用同一控件字号，界面自定义字体继续生效。

## 概览

- 先展示会话状态、当前任务与待办进度，再展示本次改动和子代理工作。
- 本次改动来自当前会话的工具记录；文件名、所在目录和增删行数分层呈现。通过“查看全部”进入文件页的“本次改动”。
- 子代理优先展示仍在进行、等待或待确认的任务；完整记录通过“查看全部”打开。
- 上下文、费用和工具调用合并为“资源与用量”，Token 与缓存细项按需展开。
- 模型、会话 ID 和会话文件等元数据默认收起，展开后仍可复制或打开。
- 概览内容右侧固定预留 16 点滚动条留白，文本与行末按钮不会进入滚动条区域；滚动条显示或隐藏时内容宽度保持稳定。

## 文件

本地项目的项目标题、系统文件管理器入口、刷新、隐藏文件开关、收起目录、路径搜索与排序固定在列表上方。点击项目标题旁的文件夹按钮可打开当前项目目录：Windows 使用资源管理器，macOS 使用 Finder，Linux 使用系统文件管理器。

文件面板跟随当前选中的项目，包括从左侧项目列表、输入框项目菜单或命令面板切换的情况。标题、文件列表、搜索与打开操作使用同一项目目录；切换时立即移除旧项目的文件行，等待新目录加载。选择项目不会迁移已有会话的归属。

- **全部文件**：现有文件树与文件路径筛选，保留预览、编辑及右键操作。
- **本次改动**：当前会话记录中属于这个项目的文件，显示增删行数，并可打开原始改动记录。当前会话属于其他项目时显示空状态，切回原项目后恢复其改动记录。

两种范围共用搜索内容和排序，各自保留滚动位置。排序支持名称、修改时间、格式（扩展名）和大小的两个方向；A → Z 为名称或扩展名正序，↓ 为最近修改优先或大文件优先，↑ 为最早修改优先或小文件优先。文件树始终保留目录优先及目录层级，切换排序不收起目录、不清空搜索。搜索结果和本次改动也使用相同排序；修改时间与大小来自后台读取的本地文件信息，已删除或无法读取信息的文件排在已知信息之后。刷新会更新文件信息。排序仅在当前应用运行期间保留。

当前会话的历史改动不等同于仓库中尚未提交的改动；工具记录中的项目外路径不会混入项目文件列表。远程文件浏览继续使用现有远程入口。

## Git

分支、上游和同步操作固定在顶部。“更改”与“历史”分别浏览，各自保留滚动位置。

- **更改**：冲突入口优先，其后按未暂存、已暂存分组；文件名和目录分行。冲突文件不会重复列入普通改动组。
- **提交区**：固定在更改页底部，保留摘要生成、最近说明、修订、全部提交及提交并推送。存在冲突时，提交操作禁用并说明原因。
- **历史**：保留提交搜索、分页、图谱、提交详情和右键操作。离开再返回后，搜索内容仍保留。
- 更改、历史及 Git 列表弹窗统一在滚动内容右侧预留 16 点，文件名、日期和行末操作避开覆盖式滚动条；空位始终保留，滚动时不挤动内容。

后台仓库状态刷新不应重建文件搜索或正在编辑的提交说明；在更改与历史之间切换也不会清除提交草稿。Git 操作继续调用原有仓库逻辑和确认流程。
