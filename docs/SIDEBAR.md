# 桌面端右侧栏

右侧栏按“概览、文件、Git”组织，沿用应用当前主题。切换入口和现有文件、仓库操作保持一致。

## 概览

- 先展示会话状态、当前任务与待办进度，再展示本次改动和子代理工作。
- 本次改动来自当前会话的工具记录；文件名、所在目录和增删行数分层呈现。通过“查看全部”进入文件页的“本次改动”。
- 子代理优先展示仍在进行、等待或待确认的任务；完整记录通过“查看全部”打开。
- 上下文、费用和工具调用合并为“资源与用量”，Token 与缓存细项按需展开。
- 模型、会话 ID 和会话文件等元数据默认收起，展开后仍可复制或打开。

## 文件

本地项目的项目标题、刷新、隐藏文件开关、收起目录与路径搜索固定在列表上方。

- **全部文件**：现有文件树与文件路径筛选，保留预览、编辑及右键操作。
- **本次改动**：当前会话记录中属于这个项目的文件，显示增删行数，并可打开原始改动记录。

两种范围共用搜索内容，各自保留滚动位置。当前会话的历史改动不等同于仓库中尚未提交的改动；工具记录中的项目外路径不会混入项目文件列表。远程文件浏览继续使用现有远程入口。

## Git

分支、上游和同步操作固定在顶部。“更改”与“历史”分别浏览，各自保留滚动位置。

- **更改**：冲突入口优先，其后按未暂存、已暂存分组；文件名和目录分行。冲突文件不会重复列入普通改动组。
- **提交区**：固定在更改页底部，保留摘要生成、最近说明、修订、全部提交及提交并推送。存在冲突时，提交操作禁用并说明原因。
- **历史**：保留提交搜索、分页、图谱、提交详情和右键操作。离开再返回后，搜索内容仍保留。

后台仓库状态刷新不应重建文件搜索或正在编辑的提交说明；在更改与历史之间切换也不会清除提交草稿。Git 操作继续调用原有仓库逻辑和确认流程。
