# 内置主题

内置外观围绕长时间阅读、编程和多会话工作设计。默认主题及五套可选主题分别提供浅色、深色配色；跟随系统、纸白和炭黑共享默认配色，分别沿用现有的自动、浅色、深色切换方式。

## 六种视觉方向

| 主题 | 视觉性格 | 浅色底 / 强调色 | 深色底 / 强调色 | 主题圆角 |
| --- | --- | --- | --- | --- |
| 默认 | 冷纸、墨青，清楚区分导航、正文、输入区 | `#f7f9f9` / `#285d63` | `#151b1d` / `#91c6cd` | 8 |
| 森系绿 | 苔灰底、蕨叶绿，色彩集中于操作与选中态 | `#f5f7f3` / `#42623b` | `#171d18` / `#a9c697` | 10 |
| 石墨灰 | 银灰、铅灰，偏冷的精密工具感 | `#f2f3f4` / `#424b55` | `#1a1c20` / `#cdd5e0` | 6 |
| 海盐蓝 | 雾白、灰蓝、深海，减少电蓝的刺激感 | `#f3f7fa` / `#35617f` | `#131e28` / `#9ac4de` | 10 |
| 羊皮纸 | 米纸、棕墨、赭红；暗色延续暖纸与炭墨 | `#f4f0e6` / `#88462f` | `#211e19` / `#e1aa86` | 6 |
| 终端（TUI） | 冷炭、磷青、琥珀，操作与代码形成清楚分工 | `#f1f5f5` / `#22656b` | `#121a1d` / `#89d2ce` | 4 |

圆角值使用 NSGo 逻辑尺寸，作用于读取主题圆角的控件；局部已经明确尺寸和圆角的组件保持现有规则。

羊皮纸的纸感来自正文、侧栏、浮层、输入区之间的纸色层次，以及棕墨和赭红的分工。深色版使用暖炭底、浅纸色文字与柔和陶土色操作，代码区域保留清楚的等宽字体。它沿用现有阅读层级与中文字体回退，用户指定的界面字体、代码字体和聊天字号继续优先。

## 调色原则

- 页面、导航、内容面板、浮层、输入框分别定义颜色；浅色与深色独立调色。
- 正文、次要文字、辅助文字、强调文字、代码和语义文字，在基础表面及悬停、按下表面上按至少 **4.5:1** 的对比度设计。
- 主操作的普通、悬停、按下各有独立填色，按钮文字在三种状态下均保持至少 **4.5:1** 的对比度。
- 焦点色相对基础表面、输入边界相对输入底色保持至少 **3:1** 的对比度。选区、滚动条、开关轨道与滑块使用各主题的角色色。
- 错误、警告、成功、信息和思考状态分别调色；错误和警告保留原有文字、图标等状态提示。
- 中文界面继续使用现有 CJK 字体回退，代码继续使用现有等宽字体栈。主题不覆盖用户的字体或字号偏好。

## 实现与兼容

- `internal/viewkit/theme.go`：默认浅深配色、共享角色色与状态色，桌面、移动端和 Web 共用。
- `internal/workbench/addon_palettes.go`：桌面端五套主题的完整浅深角色色与主题圆角。
- `internal/workbench/theme_palette_test.go`：角色完整性、对比度、独立交互状态和表面分层的定向回归测试。

主题 ID、名称、配置格式、导入导出方式和插件接口保持现状。已有主题选择直接得到新版配色，无需迁移设置。移动端与 Web 继续使用共享默认主题；桌面端保留完整主题选择器。
