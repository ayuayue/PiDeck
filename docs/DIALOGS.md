# 桌面弹窗尺寸

操作弹窗按用途选择逻辑宽度，不跟随聊天栏宽度设置：

| 类型 | 首选宽度 | 用途 |
| --- | ---: | --- |
| 简单操作 | 400 点 | 确认、重命名 |
| 标准表单 | 560 点 | 列表选择、认证等普通操作 |
| 单栏编辑 | 640 点 | 快捷短语、任务表单、翻译、搜索及多行编辑 |
| 双栏管理 | 840 点 | ACP 预设、提示词库 |

宽度常量集中在 `internal/viewkit/dialog.go`。桌面端通过 `internal/workbench/ui_dialog_layout.go` 将首选尺寸限制在当前窗口内，并保留系统标题栏和边缘空间。聊天栏宽度仍只控制聊天内容。

- 批量移除项目：列表随项目数量增长，最高 240 点，更多项目在列表内滚动。
- 快捷短语与回复规则：首选总高度 464 点；矮窗口进一步缩小，保留底部操作。
- ACP 预设：主体首选高度 400 点；列表和编辑区分别滚动，保存操作不随编辑内容滚动。窗口宽度小于 720 点时改为上下排列。
- 认证：按内容自然撑高，移除 400 点的最小高度；供应商选择固定在顶部，较长的认证表单独立滚动。
- 搜索、快捷键、并行问询和提示词库使用有界编辑区域；图片生成与识图表单限制滚动主体的高度。

本轮统一桌面应用的尺寸规则，保留移动端底部面板、图片预览、回复长图、原生系统对话框和提示浮层各自的布局。

针对性布局回归位于 `internal/workbench/dialog_layout_test.go`；聊天宽度独立性回归位于 `internal/workbench/chat_width_test.go`。
