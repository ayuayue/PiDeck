# 滚动区域内容避让排查

本次由右侧概览与 Git 更改区的遮挡问题扩展到应用滚动布局的源码排查。修复涉及 61 个源码文件；数量包括并行新增的诊断日志管理文件中的局部留白调整，不代表 61 个问题都已通过实机复现。诊断管理文件为其他任务并行新增，其局部留白修复保留在工作区，随所属诊断改动合并，不随本次提交纳入。

## 原因与处理

- 多个滚动视口的内容直接贴右排列，滚动指示器出现时会压在文本、日期或操作按钮上。
- 概览另有一个独立问题：长路径的 Tooltip 外层禁止收缩，复制按钮会被挤出窄栏。现在路径所在的行内容器允许收缩，按钮保留位置。
- 对确认缺少避让空间的内容容器，复用 `viewkit.PanelInset`，在滚动内容内侧预留稳定的 16 点右留白。虚拟列表使用其内容 Padding；普通 Scroll 修改内层内容，不通过外层视口 Padding 移动滚动条。
- 不随滚动条显隐改变宽度，不修改滚动位置、窗口化、键盘操作、发送或 Git 操作逻辑，不修改 NSGo 模块缓存或新增全局滚动条主题。

## 排查范围与结果

| 范围 | 本次处理 |
| --- | --- |
| Git | 更改、提交历史、文件历史、分支选择、冲突、远程、标签、暂存栈、未推送提交和 blame 等列表的内层留白 |
| 桌面项目与会话 | 概览长路径、项目分组与移除、远程文件、会话关联与分组建议、文件搜索、本次改动、归档、分支、收藏与任务等列表 |
| 桌面设置与弹窗 | 设置导航与搜索、用量、模型、供应商、资源、MCP、提示词、技能、ACP、代理、通知、导入、询问表单、翻译与媒体结果、浏览器审批详情、诊断管理动作等滚动内容 |
| 客户端 | 项目侧栏、命令建议、批量问题、文件与文件正文、Git 与分支、搜索、任务、收藏、评审、模型选项、子代理和工具输出 |
| 共享视图 | 错误边界的可滚动错误详情 |

桌面排查覆盖直接声明的 Scroll/List 及内置 Command、SuggestList 的使用位置；客户端排查同时检查了共享视图。判断依据是视口到文本/操作控件的实际空间，不是机械比较某一个 Padding 数值。主聊天、欢迎页、已含有效内层留白的卡片或分组保持原状。

内置 Command/SuggestList 使用运行库自带的行布局，本次未复制或修改运行库组件。原生多行编辑器、终端和 WebView 的滚动属于各自宿主，未按普通 Scroll 内容模型强制添加留白。这些位置未作跨平台实机无覆盖保证。

## 针对性验证

以下测试通过：

- `TestOverviewKeepsContentClearOfScrollbar`：260/420 点概览栏、实际溢出内容和长路径，检查重命名及复制等行末按钮。
- `TestGitDrawerKeepsRowsClearOfScrollbar`：260/420 点、平铺/目录树两种变更布局、长路径及长提交标题，检查变更和历史的行末控件。
- `TestGitFileHistoryKeepsRowsClearOfScrollbar`：260/420 点文件历史、长作者名和长提交标题。
- `TestProjectGroupListKeepsChoicesClearOfScrollbar`：360/600 点窗口中的长虚拟项目列表，检查项目选项边界。
- `TestMobileCommandsKeepRowsClearOfScrollbar`：320/480 点、24 条命令建议的溢出列表，检查每一行边界。
- `TestOverviewCopyID`、`TestGitSidebarKeepsDraftAndSeparatesConflicts`、`TestMobileGit`、`TestMobileSlashCommandSendAndRecover`：覆盖原有复制、草稿、冲突区分和客户端操作。

这些是无窗口布局与交互回归；没有重启桌面应用，没有执行全仓库或全平台构建，也没有将源码排查等同于各平台实机验收。
