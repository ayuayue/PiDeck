# 本机文件编辑与行号定位

桌面端可以编辑本机项目中的文本文件，单个文件上限为 4 MiB。二进制或过大的文件会给出拒绝原因。

## 预览与定位

- 从文件树或最近文件直接打开 Markdown、HTML、CSV / TSV 时，先显示预览；点击“编辑文本”进入编辑器。
- 文件内容搜索结果、会话中的文件引用带有行号时，Markdown、HTML、CSV / TSV 会直接打开源码并定位到对应行。
- 文件引用不带行号时，沿用该类型的普通打开方式；图片、PDF、压缩包等仍进入预览或文件信息页。
- 打开另一个文件或切换到预览会保留已打开文本的未保存修改。
- 文件引用在后台解析期间，若已打开其他文件、关闭文件区域、切换标签、页面或会话，迟到的结果不会抢回当前界面；过期的读取失败也不会再弹出提示。

## 转到行与状态栏

使用“转到行”（`Ctrl+G`，macOS 为 `⌘G`）输入行号，回车或点击“转到”定位。对话框关闭后键盘焦点回到编辑器，可直接继续输入或移动光标；取消不改变原光标位置。

窄文件栏会优先保留行列位置、行数和保存状态，较长的路径缩略显示，避免将状态挤到视口外。

## 重命名与保存

在应用的文件树中重命名文件或文件夹后，已打开的文件标签会同步更新名称、路径和语法高亮。当前未显示的标签也会更新，未保存文本继续保留，随后保存会写入新路径。文件正在保存时，重命名该文件或包含它的文件夹会暂时拒绝并提示“正在保存…”，保存完成后可重试。

关闭有未保存修改的文件或编辑器时会要求确认。磁盘文件被外部程序改动后，保存会拒绝覆盖并提示冲突；先保留自己的修改，再决定如何重新读取和合并。

连续发起“重新读取”时，仅最近一次请求会更新编辑缓冲和加载状态。较早请求迟到的成功或失败结果，不会覆盖新文本、清除未保存标记或替换当前错误。
