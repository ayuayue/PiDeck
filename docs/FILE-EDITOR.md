# 本机文件编辑与行号定位

桌面端可以编辑本机项目中的文本文件，单个文件上限为 4 MiB。二进制或过大的文件会给出拒绝原因。

## 预览与定位

- 从文件树或最近文件直接打开 Markdown、HTML、CSV / TSV 时，先显示预览；点击“编辑文本”进入编辑器。
- 文件内容搜索结果、会话中的文件引用带有行号时，Markdown、HTML、CSV / TSV 会直接打开源码并定位到对应行。
- 文件引用不带行号时，沿用该类型的普通打开方式；图片、PDF、压缩包等仍进入预览或文件信息页。
- 打开另一个文件或切换到预览会保留已打开文本的未保存修改。

## 重命名与保存

在应用的文件树中重命名文件或文件夹后，已打开的文件标签会同步更新名称、路径和语法高亮。当前未显示的标签也会更新，未保存文本继续保留，随后保存会写入新路径。

关闭有未保存修改的文件或编辑器时会要求确认。磁盘文件被外部程序改动后，保存会拒绝覆盖并提示冲突；先保留自己的修改，再决定如何重新读取和合并。
